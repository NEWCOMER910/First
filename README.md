# git

练习 Git 用的仓库。

## 常用命令

```bash
git status              # 查看当前改动
git add .               # 把所有改动加入暂存区
git commit -m "说明"     # 提交
git push                # 推送到 GitHub
git pull                # 拉取远程更新
```

## Git 三步走

1. **工作区** — 你正在编辑的文件
2. **暂存区**（stage）— `git add` 之后待提交的内容
3. **仓库**（commit）— `git commit` 之后的快照

推送到远程：`git push`
